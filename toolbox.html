🍏 苹果 iOS：Shadowrocket（小火箭）傻瓜教程

苹果手机最省心、最稳定的上网神器！只要用外区美区 Apple ID 即可下载。

📖 查看官方下载防骗教程 ↗
步骤 1：去哪儿安全下载？

1. 登录美区/外区 Apple ID 下载

国区 App Store 搜索不到小火箭！切记：千万不要在系统【设置-iCloud】里登录别人的账号！只需要打开 App Store，点击右上角头像，拉到最底部退出登录，然后登录借来的或买的美区账号，搜索 Shadowrocket ($2.99) 下载。

🚨 旺仔保命警示：如果在系统设置里登录陌生 iCloud，手机可能被远控锁定变成“砖头狗”！切记只在 App Store 商店内登录！
步骤 2：怎么导入订阅？

2. 把机场订阅一键倒进小火箭

在机场后台找到“一键导入小火箭”按钮点击，或者复制“Clash / Shadowrocket 订阅链接”。打开小火箭，点击右上角【+】号，类型选择 Subscribe (订阅)，把复制好的链接粘贴在 URL 框里，点击右上角【保存】。

💡 狗子偷懒秘籍：导入后在主界面往下拉刷新一下，节点列表就会啪的一下全弹出来啦！
步骤 3：怎么开启连线？

3. 选个顺眼的节点，开启大开关

在小火箭节点列表里，点击【延迟测试】，找个延迟几十毫秒的绿色节点点一下。然后把最顶上的【未连接】大开关往右一划！首次开启会弹出“允许添加 VPN 配置”，按提示输入手机解锁密码即可。

🐕 旺仔碎碎念：弹出 iOS 授权提示别吓一跳，那是苹果系统的防抓包护城河，输入密码给小火箭通关文牒就行！
步骤 4：搞怪技巧与分流

4. 全局路由设为【配置】，省流量！

在小火箭首页下方，把【全局路由】设置为【配置】(Config)。这样刷淘宝、看 B 站走国内直连不耗机场流量；看 YouTube、X 走国外代理！

🎉 大功告成：现在打开 Safari 浏览器输入 youtube.com 试试，快乐冲浪吧！

💻 Windows 电脑：Clash Verge Rev / Party 教程

电脑端最强大的科学上网神器！支持新协议，开机即连，打游戏看4K都不卡。

📖 查看 Windows 客户端选型 ↗
步骤 1：去哪儿安全下载？

1. 从 Github Releases 官方下载

推荐下载开源的 Clash Verge Rev 或 Clash Party。认准 Github 官方 Releases 页面，下载 `.exe` 或 `.msi` 安装包。一路点【下一步】安装到电脑。

🚨 防坑提醒：别在百度随便下带有广告的“修改版”，小心暗藏后台挖矿木马！认准开源社区原版。
步骤 2：怎么导入订阅？

2. 复制订阅链接，一键导入

打开机场后台，点击【复制 Clash 订阅链接】。打开 Clash Verge 客户端，点击左侧【订阅】(Profiles) 菜单，把链接粘贴到上方地址栏，点击【导入】(Import) 按钮。

💡 小技巧：导入成功后，右键点击订阅卡片选择“定时更新”，设置成 24 小时更新，节点永不上线失效！
步骤 3：怎么开启代理？

3. 选择节点，勾选【系统代理】

点击左侧【代理】(Proxies) 菜单，选择“规则”模式，找个低延迟节点点一下。然后点击左侧【设置】，开启【系统代理】(System Proxy) 开关，按钮变绿就说明成功啦！

🎮 打游戏进阶（TUN 模式）：如果要玩 Steam / 绝地求生等网游，把【TUN 模式】勾上，相当于内置网游加速器！
步骤 4：退出与排障

4. 关电脑前记得退出系统代理

不想上网时，直接右键点击任务栏右下角的软件小图标，选择【退出】（它会自动帮你把 Windows 系统代理关掉，避免下次开机没开软件导致网页打不开）。

🐶 旺仔救急：如果电脑网页突然打不开，检查一下 Windows 设置-网络-代理，看看是不是被死锁了！

🤖 安卓手机：v2rayNG / Clash Meta 教程

开源免费，无广告！支持华为、小米、OPPO、vivo 等全系安卓手机。

步骤 1：下载安装包

1. 下载 v2rayNG 或 Clash Meta APK

在官网或者 GitHub Releases 下载 `.apk` 安装包。安装时如果手机提示“来自未知来源”，点击【允许安装】即可。

💡 推荐选哪个：新手小白推荐 v2rayNG（界面极其简单）；喜欢分流高级玩家推荐 Clash Meta。
步骤 2：导入订阅

2. 复制订阅，一键批量导入

以 v2rayNG 为例：在机场后台复制 v2ray 订阅链接。打开 v2rayNG，点击左上角【三条杠菜单 - 订阅设置】，点击右上角【+】号，粘贴链接保存。然后返回主界面，点击右上角【三点 - 批量更新订阅】。

🐕 旺仔汪汪：更新完之后，刷的一下节点名字就全出来啦！
步骤 3：启动连线

3. 测试延迟，点击右下角 V 字按钮

点击右上角【测试全部节点延迟】，挑个绿色低延迟的节点点一下。然后点击右下角【圆圈 V 字形连接按钮】，允许系统建立 VPN 连接。

🎉 成功标示：通知栏出现小钥匙或 VPN 标志，说明已经通畅啦！
步骤 4：华为鸿蒙特别避坑

4. 鸿蒙 / 小米后台保活设置

华为鸿蒙或小米 MIUI 手机容易在后台把软件“杀掉”。记得在手机【设置-电池-应用启动管理】里，把 v2rayNG 改为“手动管理”，勾选【允许后台活动】！

🚨 防后台挂掉：设好后台保活，锁屏听 YouTube 音乐才不会突然断掉！

🍎 macOS 苹果电脑：Clash Verge / Party 教程

适配 Apple Silicon (M1/M2/M3) 及 Intel 芯片，原生流畅无缝对接。

📖 查看 macOS 安装说明 ↗
步骤 1：下载 dmg 安装

1. 下载对应芯片的 .dmg 包

根据 Mac 芯片选择：M1/M2/M3 选 aarch64 / arm64 版本；Intel 选 x64 版本。下载后双击 `.dmg`，把图标拖进 Applications 文件夹。

🚨 Mac 提示已损坏？如果提示“无法打开，因为无法确认开发者”，去系统偏好设置 - 隐私与安全性 - 点击【仍要打开】！
步骤 2：导入与配置

2. 粘贴订阅链接并启动代理

复制机场 Clash 订阅链接，在 Clash 软件 Profiles 页面导入。然后在菜单栏顶部勾选【Set as System Proxy】（设为系统代理）。

💡 极简开关：在 Mac 顶部状态栏小猫咪图标上右键，可以直接切节点和设代理！

🐕 狗窝避坑 Q&A（小白常见破坑答疑）

❓ 为什么小火箭/Clash 连接后提示“允许添加 VPN 配置”？

别慌！那是 iOS 和安卓系统的安全护城河协议。任何代理软件首次启动时，系统都会弹出提醒。点击“允许”并输入手机锁屏密码，给软件发放通关钥匙即可。

❓ 导入订阅链接时报错 "Net Error" 或 "更新失败" 怎么办？

大概率是因为你当前手机没开任何网络节点，或者机场订阅入口域名临时波动。尝试：1. 切换成 4G/5G 移动网络重试；2. 检查订阅链接有没有少复制字母；3. 到机场后台换备用订阅链接。

❓ 为什么开启代理后，国内淘宝、B站、微信变慢了？

因为你的软件开启了“全局代理”模式，导致访问国内网站也绕道国外服务器了！请在软件设置中把【全局路由 / 模式】修改为【Rule / 配置 / 绕过大陆】，国内流量直连，国外流量代理，省流又极速！

❓ 电脑开机后突然所有网页都打不开，显示“无网络”？

这是因为你之前强行关闭了电脑，导致 Windows 系统的代理开关没自动关掉。解决方法：打开 Windows【设置 - 网络和 Internet - 代理】，把“使用代理服务器”开关手动关掉，或者重新打开 Clash 客户端即可恢复！
