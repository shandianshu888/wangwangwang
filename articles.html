“机场”和 VPN 是一回事吗？

小火箭 Shadowrocket 自带节点吗？

小火箭有 Android 或 Windows 版本吗？

官方 App Store 页面主要面向 Apple 平台。Android 或 Windows 上遇到同名安装包时，应先核对开发者和来源，不要把第三方同名软件当成官方版本。

小火箭导入订阅后为什么不能连接？

小火箭规则模式、全局和直连怎么选？

日常优先规则模式；全局适合临时确认是否为规则问题；直连用于恢复原网络或做对照。查看三种模式的区别。

Clash Party 是图形客户端，Mihomo 是负责规则、连接和流量处理的核心项目之一。客户端本身不出售节点。查看完整关系。

系统代理只覆盖遵循系统设置的应用；TUN 覆盖通常更广，但权限、DNS 和路由冲突更复杂。查看适用场景。

Fake-IP 和真实 IP 模式怎么选？

两种方式的 DNS 返回和兼容行为不同。选择时应看客户端文档、局域网需求和目标应用表现，不应从陌生配置直接复制整段 DNS 设置。
